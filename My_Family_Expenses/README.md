# My Family Expenses

## Project Description
I created My Family Expenses to help me keep track of my family’s spending each month. I wanted a simple way to organize expenses and see how much money is spent.The program allows me to add expenses, view them, search by date or category, and calculate the total. I also added JSON to save monthly records and CSV to export expenses into a file that I can open in Excel.

# Running My Project

To run my family expense tracker, I open the My_Family_Expenses folder in VS Code and use the terminal to run:
python src/main.py
The program displays eight options. I can add family expenses, check my spending, save monthly records in JSON, or export a CSV report.

# My Project Files

I divided my project into separate Python files to keep everything organized.

* main.py starts my program.
* family_menu.py' displays the menu and connects the options.
* monthly_expenses.py handles adding, viewing, searching, and calculating expenses.
* json_storage.py saves and opens monthly expense records.
* csv_report.py creates a CSV report of my expenses.
